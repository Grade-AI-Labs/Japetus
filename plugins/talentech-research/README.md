# talentech-research

UX research skills, shared by Product Design and Product Management.

## Install

```
/plugin marketplace add Grade-AI-Labs/Japetus
/plugin install talentech-research@talentech-agentic-skills
```

## What ships

Roughly in the order a study runs:

| Skill | Use it to |
| --- | --- |
| `/talentech-research:method-selector` | Choose the right method for a question, or learn that research can't answer it ("No, but...") |
| `/talentech-research:mixed-methods` | Combine qualitative and quantitative work and pick a design |
| `/talentech-research:research-plan` | Write a research plan or brief that aligns stakeholders |
| `/talentech-research:ethics-checklist` | Review a study for consent, privacy, vulnerable participants and sensitive topics; draft consent and debrief |
| `/talentech-research:interview-guide` | Build a generative 1-on-1 interview guide from the research goals |
| `/talentech-research:survey-builder` | Design, write and analyse surveys; use validated scales such as SUS and SEQ |
| `/talentech-research:affinity-synthesis` | Turn interview data into patterns and evidence-checked recommendations |
| `/talentech-research:extract-insights` | Extract atomic insights from a report, ready for the insights repository |
| `/talentech-research:shareout` | Present findings so stakeholders act on them |
| `/talentech-research:business-case` | Justify a study, tool or headcount with costs, benefits and risks |
