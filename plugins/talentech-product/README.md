# talentech-product

Skills for Product Management.

## Install

```
/plugin marketplace add https://gradegroup.ghe.com/tech/talentech-agentic-marketplace.git
/plugin install talentech-product@talentech
```

Depends on [`talentech-core`](../talentech-core), which publishes the finished PRD to Confluence.

## What ships

| Skill | Use it to |
| --- | --- |
| `/talentech-product:problem-to-prd` | Take a new idea from raw problem to a developer-ready PRD in two gated stages: lock the problem statement first, then write the PRD with goals, non-goals, edge cases, success metrics and risks |
